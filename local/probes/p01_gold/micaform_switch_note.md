Before we spend anything on Micaform I had Theo's comparison checked cell by cell against
Tarnwell's own pages, the Mixbench review and our house rules, and the picture is not quite
the one his table paints.

Proximity and Intensity are not new with Micaform. The review says the old Racklane Capsule
module already had both, and the Racklane reference simply never mentions them, so Theo's
noes for FT-2 and FT-3 on the rack side do not hold. The tape stage (FT-6) runs the
other way: Tarnwell retired it from the Capsule module in Racklane 4.2, so the rack
chain no longer has one and Theo's Yes on that side has to go, and the Wow control went
with it.

Two things on the reference pages do not count for us. Tarnwell's 4.4 update brings the
tape stage back and drops the sidechain key, but we run 4.3, so the audit stops there. The
Micaform page also lists a sidechain key and a low cut as coming in 1.2, which is not the
release on sale, so neither counts as something Micaform has today.

Once the matrix is corrected, the rack chain and Micaform have 5 features in
common, and 2 are Micaform only: the tape stage and the dual capsule blend.
What the move costs us is the sidechain key input on the Valve Stage, which Micaform does
not offer.

My view is that the blend is worth having, but I would like one session without the
sidechain before we retire the rack. The cell by cell audit is in the matrix file if you
want the detail.
