Before we spend anything on Micaform I had Theo's comparison checked cell by cell against
Tarnwell's own pages, the Mixbench review and our house rules, and the picture is not quite
the one his table paints.

Proximity is not new with Micaform: the review says the old Racklane Capsule module had it,
the Racklane reference never mentions it, and nothing in the release history took it away,
so Theo's No on the rack side for FT-2 does not hold. Intensity is a different story. The
Capsule module did have it, but Tarnwell retired the control in Racklane 4.3, the release we
run, so on that row Theo's No is right for the wrong reason. The tape stage (FT-6) runs the
other way again: Tarnwell retired it from the Capsule module in Racklane 4.2, so the rack
chain no longer has one and Theo's Yes on that side has to go, and the Wow control went
with it. The low cut left the chain too, moved to the separate Room module in 4.3.

Some things on the reference pages do not count for us. Tarnwell's 4.4 update brings the
tape stage back and drops the sidechain key, but we run 4.3, so the audit stops there. The
Micaform page lists a sidechain key and a low cut as coming in 1.2, which is not the release
on sale, and what each Tarnwell page says about the other product is not evidence for it.

Once the matrix is corrected, the rack chain and Micaform have 4 features in
common, and 3 are Micaform only: the Intensity control, the tape stage and the dual
capsule blend. What the move costs us is the sidechain key input on the Valve Stage, which
Micaform does not offer.

My view is that the blend is worth having, but I would like one session without the
sidechain before we retire the rack. The cell by cell audit is in the matrix file if you
want the detail.
