Before we spend anything on Micaform I had Theo's comparison checked cell by cell against
Tarnwell's own pages, the Mixbench review, the studio inventory and our house rules, and the

The first thing to hold onto is which Racklane we are talking about. The live room rig that
carries the TM-9 chain is held at 4.2.10 until the album closes, so the audit reads Tarnwell's
release history only that far. The 4.2.11 point release, the 4.3 on the edit suite and the 4.4

Proximity is not new with Micaform: the review says the old Capsule module had it, and nothing
up to 4.2.10 took it away. Intensity is different, because Tarnwell retired it in 4.2.7, so
Theo's No there is right for the wrong reason. The tape stage (FT-6) runs the other way:
Tarnwell retired it from the Capsule module in Racklane 4.2, so the rack chain no longer has
one and Theo's Yes on that side has to go, and the Wow control went with it. The low cut left
for the Room module in 4.2.3 and came back in 4.2.10, so we still have it. The polarity flip
Theo saw on the Micaform launch panel was dropped in 1.1, while our rack gained one in 4.2.10.

Some things on the reference pages do not count for us either. The Micaform page lists a
sidechain key and a low cut as coming in 1.2, which is not the release on sale, and what each
Tarnwell page says about the other product is not evidence for it. Theo also pasted the blend
row twice; it is one feature and I have counted it once.

Once the matrix is corrected, the rack chain and Micaform have 3 features in
common, and 4 are Micaform only: the Intensity control, the tape stage, the dual capsule blend
and the preset browser. What the move costs us is the sidechain key input on the Valve Stage
and the polarity flip, neither of which Micaform 1.1 offers.

My view is that the blend is worth having, but I would like one session without the
sidechain before we retire the rack. The cell by cell audit is in the matrix file if you
want the detail.
