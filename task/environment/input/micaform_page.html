Micaform

Microphone modelling for the Tarnwell TM-9, in one plugin. This page describes Micaform 1.1, updated 12 May 2026.

Features

  • A capsule model selector with eighteen modelled capsules.
  • Proximity and Intensity controls on the front panel.
  • A valve drive stage after the capsule.
  • A tape stage after the valve drive.
  • Dual capsule blend: two capsule models blended inside one instance.
  • Tracking mode for zero added latency while recording.

What's new in 1.1

  • Oversampling at 2x and 4x.
  • A resizable window.

Coming in 1.2

Planned for the autumn release, free to 1.x owners:

  • A sidechain key input for the valve drive.
  • A low cut filter ahead of the capsule model.

Questions

Does Micaform take a sidechain key? Not in 1.1: Micaform 1.1 has no sidechain input. A key input is planned for 1.2, above.

Which hosts does it run in? Any VST3, AU or AAX host.
