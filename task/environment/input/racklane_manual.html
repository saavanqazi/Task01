Racklane 4 — module reference

Archived reference page, Tarnwell Audio. The module sections below were written for Racklane 4.0. Changes made since then are listed under Release history at the foot of this page.

The Racklane host

Racklane hosts Tarnwell modules on up to eight parallel lanes. For the TM-9 microphone the usual chain is a Capsule module followed by a Valve Stage module on the same lane.

Capsule module

  • Model — the capsule model selector: one of twelve modelled capsules.
  • Low cut — off, 80 Hz or 120 Hz, ahead of the capsule model.
  • Tape — a tape stage after the capsule model.

The Capsule module has no dual capsule blend: it loads one capsule model per instance. To hear two models together, load two Capsule modules on parallel lanes.

Valve Stage module

  • Drive — the valve drive stage.
  • Bias — valve bias control, from cold to hot.
  • Sidechain key input — an external key signal can duck the drive.
